# Contributing

Contributions are welcome. Please file issues with the full ESP32-S3 variant, Windows build log tail, and whether the failure occurs at dependency install, compilation, model generation, flash, audio playback, network configuration, LED output, or microphone capture.

Use a feature branch and open a pull request. Do not commit Wi-Fi passwords, private keys, tokens, generated PlatformIO caches, or flashed memory dumps.

**Priorities:** reproducible build, reliable ES7210 dual-mic capture, WakeNet/MultiNet command verification, stable HTTPS streams, beat detection and cross-talk testing, robust setup hotspot and captive portal, and automated build validation.
